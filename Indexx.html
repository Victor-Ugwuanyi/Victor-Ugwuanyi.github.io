Sentinel — Network Intrusion Detection & Prevention

Actively developed

A live security dashboard that watches, detects, and blocks

Sentinel captures live network traffic (or replays a saved .pcap), runs it through a rule-based detection engine, and surfaces threats on a real-time web dashboard — with one-click firewall blocking for the source of an attack.

  • Live packet capture and PCAP file analysis via Scapy
  • Detects port scans, SYN floods, ICMP floods, ARP spoofing, and known-bad signatures
  • Real-time dashboard: live packet-rate chart, color-coded alert feed
  • Prevention layer: blocks a source IP directly via the OS firewall
